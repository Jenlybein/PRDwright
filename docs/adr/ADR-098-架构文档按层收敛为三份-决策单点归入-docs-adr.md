# ADR-098：架构文档按层收敛为三份，决策单点归入 `docs/adr/`

**状态**：已定（v8 清理轮，2026-11-02）。已执行。

### 背景

清理前的 `docs/architecture/` 是这样生长的：**每新增一层就往目录里堆文件**，堆到 v8 时共 39 份、1.1 MB，
其中六份 `v*/ADR.md` 装着同一批决策的**第二份副本**（97 条 ADR 已逐字搬进 `docs/adr/`），
另有 `evolution-truth.md` 在根目录装着一份"时间线真源"，而它只讲到 v3、落后 40 个提交。

三个具体症状：

1. **两套真相**：97 条 ADR 在 `docs/adr/` 与 `v*/ADR.md` 各存一份，且分歧已经开始发生——
   收敛前 `docs/architecture/v{2,4,5,6,7}/ADR.md` **五个都处于 modified**，而 `docs/adr/README.md` 明写着"不要再往那里追加"。
2. **层内文件数失控**：v2 有 7 份（含 `archive/` 四份）、v5 有 6 份（含两份专题）、v7 有 5 份（含 `DEPLOYMENT.md`），
   读者不知道"这一层该读哪一份"。
3. **悬空声明**：`evolution-truth.md` 的 §6「三份文档各看什么」只认 v1~v3，而库里有 8 层。

### 决策

1. **每层收敛为三份**：`README.md`（这层是什么、为什么做）、`ARCHITECTURE.md`（设计，专题以附录并入，正文逐字不动）、
   `roadmap.md`（排期）。**没有 roadmap 的层就少一份**，不为了凑数凭空造（v1、v2 现为两份）。
2. **决策只留一个落点**：删掉六份 `v*/ADR.md`，正文以 `docs/adr/` 的单条文件为准（编号 ADR-001 ~ 097 一字未改）。
3. **专题并入该层 `ARCHITECTURE.md`**：`T14`、`T15`、`DEPLOYMENT.md`、v2 的 `archive/*` 以附录形式并入，
   加"迁自某文件、内容逐字保留"的出处行。
4. **删掉 `evolution-truth.md`**，独有内容分流：v1 真相 → `v1/ARCHITECTURE.md` 附录 A；
   阶段总表（按 git 重算）、v2 七波重写、失真清单 → 新建的 `docs/architecture/README.md`。
5. **重写全部受影响引用**：265 处（97 条 ADR 的溯源行 + 索引表 + 层内交叉引用 + 22 处 `evolution-truth` 引用）。

### 理由

- **"两份真相"的下一站总是"两边都过期"**。这是 ADR-096 与 `CLEANUP.md` 反复出现的论证，对文档同样成立：
  与其靠纪律要求"别改错那一侧"，不如让错的那侧不存在。
- **合并的是文件，不是叙述**。所有并入都是"搬运 + 标题 + 出处行"，正文逐字不动，
  执行时用字符对账证明（v2 差 0.18%、v5/v7 差 0 字符）。历史语境没有丢，只是换了容器。
- **`evolution-truth.md` 的删除不是"删证据"**：它可复现的部分（v2/v3 阶段表）已按 git 重算后迁进新 README，
  不可复现的部分（v1 的 44/+5891/−470）被明确标注为"历史旧账"，比让他继续以"真源"身份挂着更诚实。
- **层数不是冗余源**：实测层间逐字重复只有 0~0.4%（28 字 shingle），真正的重复全在 ADR 那一维。
  所以收敛的是"每层几份"，不是"有几层"——**v1~v7 一层都没删**。

### 关键约束

- 新增决策只写 `docs/adr/ADR-098-<标题>.md` 并补索引行，`docs/architecture/v*/` 下**不再有 ADR 文件**。
- 时间线类问题看 `docs/architecture/README.md` §2（阶段总表）与 §4（已确认的失真），不再有单独的"真源文件"。
- 文档里写出的每个路径，`ls` 必须能看见——这条在本 ADR 执行后立刻用链接自检脚本验证。

### 被否决的方案

| 方案 | 理由 |
| --- | --- |
| 保留 `v*/ADR.md` 并标注"存档勿改" | 五个文件已经在 modified，说明"勿改"靠不住；留着等于把风险留给下一次 |
| 把 97 条 ADR 反向合回一份 `ADR.md` | 与"已拆成单条"倒着走，且合出来就是本 ADR 要消灭的第二份副本 |
| 删掉 v1~v5 历史层瘦身 | 实测层内文件只有 1.1MB、层间重复近 0，删层是删证据；删它没有收益，只有损失 |
| 把专题上移到 `docs/` 顶层目录 | 与"每层三份"冲突，且会让"哪层讲什么"重新变模糊 |

### 推论

- `GLOSSARY.md` 的「时间线真源」词条改为指向 `docs/architecture/README.md` §2，不再挂具体文件名。
- `docs/agents/domain.md` 的结构图与"撞上 ADR 就摆到台面上"一节同步更新。
- 已删除的 `docs/plans/`、`docs/artifacts/`、`.workbuddy/` 三处引用按「档案只加说明不改正文」处理：
  在 `docs/journal/README.md` 顶部加一段路径映射说明，正文原文保留。
