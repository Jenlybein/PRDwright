# ADR-030：版本抽屉是 ADR-015 的一次有意例外——内容操作可以有自己的面板

> 源：v2 层（原 `docs/architecture/v2/ADR.md`，已并入本目录）｜ [索引](./README.md)

**状态**：Accepted（2026-10-16 裁决并落地）

> **补记（同日）：预览的形态与删除的落点**。抽屉随后补了两个内容操作，都仍在这条边界的**内侧**：
>
> - **点某一版即预览该版正文**。形态选了「抽屉**就地加宽**到 640px」而不是「切到中间正文区」：
>   主区域由 `ViewState` 驱动，为「看一版历史」新增一个阶段要把阶段表、进度条、底栏都跟着改一遍，
>   而这件事并不需要它们参与。360px 窄栏读长文要频繁滚动的代价，由加宽抵掉——换来的是**零状态机
>   改动**。预览里也带「恢复此版本」，因为看完一版最自然的下一步就是「我就要这一版」。
> - **每一条历史版本自带「删除」**，两步确认（先展开「删除这一版？」再确认）。它就在那一行旁边，
>   正是第 1 条说的「上下文不丢」；当前版本不给这个按钮，也不给「恢复」（都是点了没用的动作），
>   只写一句「当前版本不能删除或覆盖」说明为什么。
>
> 两者都仍是**内容操作**：预览是只读的，删除删的是历史版本、不动当前正文。流程动作依旧只在底栏。
> 本文正文保留裁决当时的形态，不回改。

### Context

ADR-015 定下「底栏是全站唯一操作落点」，理由是不让用户面对「东一个西一个的按钮」，每换一屏都要重新找「下一步」在哪。这条一直被严格执行：新增入口一律先进底栏。

版本历史带来一个新形态：它天然是**一份列表**（第几版、怎么来的、什么时候），要么常驻在正文右侧、要么做成可收起的抽屉。无论哪种，如果坚持「按钮只能出现在底栏」，列表里的每一项就没法带自己的「恢复此版本」——用户得先选中某一版、再回头看底栏有没有变出按钮，**上下文（我选的是哪一版）还得额外存一份**。

而 ADR-015 真正要防的是**流程动作分散**（生成下一份 / 完成 / 返回在两处各有一个，用户不知道该点哪个），**不是「内容操作不能有自己的面板」**。把「内容操作」与「流程动作」混为一谈，会让这条规矩从「防止迷路」变成「限制表达」。

### Options

| 方案 | 优点 | 代价 |
| --- | --- | --- |
| A. 版本列表里的按钮也全部收进底栏 | 严格守住 ADR-015 的字面，无例外 | 列表项不能带自己的动作；「恢复的是哪一版」这个上下文要额外持久化；用户要来回看两处 |
| **B. 抽屉里放内容操作、流程动作仍只落底栏（推荐）** | 列表项自带动作、上下文就在眼前；ADR-015 要防的事一点没松 | ADR-015 的字面被开了一个口子，必须把边界写死，否则下次有人照此把「生成下一份」也搬进面板 |

### Decision

**选 B，并把边界钉死：**

1. **抽屉定位为内容区的一部分**，不是第二处流程落点。它内部只允许出现**内容操作**（存为新版本 / 恢复某一版）——都是「对这份文档本身做的事」。
2. **流程动作永远不进抽屉**：生成下一份、完成、返回、重新开始，一律仍只在底栏。
3. **进入抽屉的入口仍在底栏内容行**（审阅页的「版本」按钮）。用户找操作仍然只有一个地方，`ReviewStage` 也不持有抽屉状态——它只把「用户想开版本历史」这件事抛给上层。
4. **抽屉以 `--shell-action-bar-h` 作下边距，不遮底栏**：底栏永远可见、可点，主操作的位置与唯一性不受影响。
5. **抽屉是 `fixed` 浮层、默认收起**，因此**不挤中部布局**（正文仍是 768px 居中）——这次例外不牵连任何布局改造，代价仅限于「多一层浮层」。
6. 抽屉**不 import 任何 store**（纯 props in / events out），与底栏没有耦合；两个写动作的归属与加载都收在 `stores/documentVersions.ts`。

### Consequences

- **变容易**：版本列表与它自己的动作待在一处，用户不必记住「我选了第几版」再去找按钮；`AppActionBar` 的流程行一行未动，主操作仍最右且唯一。
- **变困难**：ADR-015 从「**一律**进底栏」变成「**流程动作**进底栏、**内容操作**可以有面板」，判断标准多了一条——每个新入口都要先回答「它是流程还是内容」。答案没有机器判据，只能靠 review 守，因此这条边界写在本 ADR 而不是散在代码注释里。
- **中立**：`ui/AppActionBar.vue` 的机制未变（仍是唯一**流程**落点）；本次例外只覆盖「内容操作」，`ui/VersionDrawer.vue` 是新增的独立组件，将来就算删掉它，底栏也不需要改动。
