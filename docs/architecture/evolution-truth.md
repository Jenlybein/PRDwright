### 3.3 v1 的定位

**一次性流程原型**：能问（问卷）、能聊（SSE 澄清）、能出三份文档（PRD / 接口文档 / 提示词）、
能流式看结果。会话随服务端进程结束、进度靠前端快照恢复——这就是「一次性」的含义，
也是它把全部复杂度押在「验证主链路」上的直接结果。完整设计见 `v1/ARCHITECTURE.md`。
