## 开工前必须拍板的两件事

1. **run 中间态落在哪里**（即 `generation_jobs` 表的落点，`ARCHITECTURE.md` 第 4.1 节已给出倾向，需你确认）：
   ① 新建独立 `generation_jobs` 表（**推荐**，随 Job 化一并落地，快照保持不透明）；
   ② `solutions` 表加后端自有列；③ 按 roadmap 旧稿塞进前端快照 `data`（❌ 与 ADR-009「后端不解析 `data`」直接冲突，续传要求后端读它）。
2. **R1 内部顺序**：成本计量 → failover → 续传（推荐，先装仪表再动主链路），
   还是把「断网不丢稿」的续传提到最前（代价：它同时背负 UI 改动与主链路改动）。

两件事的完整论证见 `ARCHITECTURE.md`（第 2 / 3 / 4.1 / 9 节）。
